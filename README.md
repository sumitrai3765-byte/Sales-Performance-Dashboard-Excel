# Sales Performance Dashboard — Excel
![Dashboard Preview](dashboard_screenshot.png)

## Project Overview
An interactive Sales Analytics Dashboard built in Microsoft Excel
analyzing Superstore sales data across 4 regions and 3 product
categories from 2011 to 2014.

## Tools Used
- Microsoft Excel (Advanced)
- Pivot Tables & Pivot Charts
- Power Query
- Conditional Formatting
- DAX-style Calculated Fields

## Key Features
- KPI Cards — Total Sales, Total Profit, Total Orders, Top Region
- Monthly Sales & Profit Trend (Combo Chart)
- Regional Sales Performance (Bar Chart)
- Red/Yellow/Green Conditional Formatting for regional targets
- Interactive Slicers — filter by Month, Category, Region
- Dynamic SUMIF formulas pulling live data

## Key Insights
- Total Sales: ₹22,97,200
- Total Profit: ₹2,86,397
- Top Performing Region: West
- Underperforming Region: South (-9% vs target)
- Dashboard reduced manual reporting time by ~60%

## How to Use
1. Download the Excel file
2. Open in Microsoft Excel 2016 or later
3. Use the slicers on the right to filter by Month, Category or Region
4. All charts and KPI cards update automatically
